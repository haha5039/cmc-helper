MANUAL GUIDE

발신·수신 역할을 직접 바꾸려면

CMC 9.1.00.15에서 확인한 인증·역할 예외 준비를 기준으로 설명합니다. 이 웹 페이지는 코드를 계산하며, 휴대폰 설정을 직접 변경하지 않습니다.

CMC 기기 역할
값역할용도
pd발신 기기이 휴대전화의 전화·문자를 다른 기기에 제공합니다.
sd수신 기기다른 휴대전화의 전화·문자를 이 기기에서 받습니다.
역할 예외 준비와 역할 변경은 별도입니다.

휴대전화에 sd를 유지하려면 CMC 내부의 test_flag 역할 예외가 필요합니다. 개발자 화면은 인증을 거쳐 열어야 합니다. Apply and Reset과 테스트 사용 OFF는 CMC 초기화·재부팅을 요청할 수 있으므로 이 절차에서 사용하지 않습니다.

  1. 초기 설정과 원래 역할을 확인합니다.

    역할을 바꿀 기기에서 ‘다른 기기에서도 전화/문자하기’ 초기 설정을 마칩니다. 아래 상태 확인 명령으로 원래 역할을 기록하세요. CMC 사용을 끄기 전에 다음 인증·역할 예외 준비부터 진행합니다.

  2. 인증 후 테스트 사용을 켭니다.

    CMC 정보 화면에서 앱 이름을 10번 누릅니다. 표시된 KEY로 위 계산기에서 인증코드를 만들고 삼성 인증창에 입력하세요. 개발자 화면에 들어간 뒤 테스트 사용 스위치를 ON으로 둡니다. 이미 ON이면 끄지 않고 그대로 둡니다. CMC 9.1.00.15에서는 이 인증된 경로가 내부 test_flag를 준비하는 데 중요합니다.

    DeveloperActivity만 직접 실행하면 화면의 ON 표시와 내부 역할 예외 상태가 다를 수 있습니다. 정보 화면이 바로 닫히면 CMC 초기 설정 상태를 먼저 확인하세요.

  3. CMC 사용을 끄고 역할 값을 변경합니다.

    삼성 CMC 화면에서 역할을 바꿀 기기의 통화·메시지 사용을 모두 끕니다. 아래 세 사용 값이 모두 0인지 확인한 뒤 원하는 역할 명령 하나를 실행합니다. 이 과정에서 서버 값이나 글로벌 활성화 값을 강제로 바꾸지 않습니다.

  4. 값이 유지되는지 확인합니다.

    변경 직후와 약 3초 뒤에 역할을 다시 읽습니다. sd가 pd로 되돌아가면 인증된 역할 예외 준비와 CMC 버전을 확인하세요. 발신으로 돌아가려면 같은 꺼짐 조건에서 pd를 지정합니다. 개발자 테스트 사용 OFF를 역할 전환 버튼처럼 사용하지 마세요.

  5. CMC에서 기기 연결을 마칩니다.

    기존 CMC 설정 창을 닫았다 다시 열고, 필요한 초기 설정·삼성 계정 확인·QR 연결과 사용 설정을 진행합니다. 처음 연결을 시험할 때는 두 기기를 같은 삼성 계정과 같은 Wi-Fi에 두면 확인하기 쉽습니다. 역할 값과 실제 연결은 별개이므로 전화와 SMS를 각각 시험하세요.

수동 변경 명령 보기 · PC ADB / Shizuku shell

다음은 PC ADB 기준입니다. 휴대폰에서는 Shizuku에 연결된 shell 환경(rish 등)에서 앞의 adb shell을 제외합니다. 일반 터미널 앱만으로 설정 쓰기 권한이 생기지는 않습니다. 위 인증·역할 예외 준비를 먼저 마친 뒤 사용하세요.

1. 원래 역할과 꺼짐 상태 확인

adb shell settings get global cmc_device_type
adb shell settings get global cmc_activation
adb shell settings get global cmc_call_activation
adb shell settings get global cmc_message_activation

원래 역할을 기록하고, 세 사용 값이 모두 0인지 확인합니다. 사용 중이거나 상태를 읽지 못하면 변경하지 마세요.

2. 원하는 명령 하나만 실행

수신 기기로 변경:

adb shell settings put global cmc_device_type sd

발신 기기로 변경:

adb shell settings put global cmc_device_type pd

3. 적용 직후와 약 3초 뒤 확인

adb shell settings get global cmc_device_type

원하는 값이 유지되는지 확인한 뒤 CMC 화면에서 사용 설정과 기기 연결을 진행합니다. 이 수동 절차는 Helper의 자동 저널·롤백을 대신하지 않으므로, 원래 역할 기록을 남겨 두세요.

원래 역할로 복원하려면

CMC의 통화·메시지 사용을 모두 끈 뒤, 기록한 원래 역할이 pd 또는 sd라면 위 명령으로 그 값을 다시 지정합니다. 원래 조회 결과가 null로 키가 없었던 경우에는 다음 명령으로 키 부재 상태를 복원합니다.

adb shell settings delete global cmc_device_type

test_flag 해제는 역할 복원과 다른 작업입니다. 재부팅·초기화를 피하려면 개발자 화면의 OFF나 Reset을 직접 누르는 대신, 지원 버전에서 CMC Helper의 ‘역할 예외 해제’ 안내를 확인하세요.

이 절차의 확인 범위는 CMC 9.1.00.15입니다. 다른 버전은 인증·역할 저장 동작이 다를 수 있습니다.
