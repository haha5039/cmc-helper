MANUAL GUIDE

발신·수신 역할을 직접 바꾸려면

CMC 9.1.00.15의 인증·개발자 설정 동작을 기준으로 설명합니다. 이 웹 페이지는 코드를 계산하며, 휴대폰 설정을 직접 변경하지 않습니다.

CMC 기기 역할
값역할용도
pd발신 기기이 휴대전화의 전화·문자를 다른 기기에 제공합니다.
sd수신 기기다른 휴대전화의 전화·문자를 이 기기에서 받습니다.
인증된 개발자 화면에서 진행하세요.

역할 값만 바꾸는 것으로 내부 test_flag가 켜지지는 않습니다. 먼저 인증을 거쳐 테스트 사용을 준비합니다. 아래 개발자 화면의 Apply and Reset은 CMC 등록·설정을 초기화하고 기기 재부팅을 요청하므로, CMC를 다시 설정할 수 있을 때 진행하세요.

  1. CMC 초기 설정을 마칩니다.

    역할을 바꿀 기기에서 ‘다른 기기에서도 전화/문자하기’ 초기 설정을 완료하고 CMC 정보 화면을 엽니다. 초기 설정 상태가 꺼져 있으면 정보 화면이 바로 닫힐 수 있습니다.

    초기 설정 중 기존 발신 폰을 이 기기로 변경한다는 확인창이 나오면, 수신 기기 추가가 아니라 발신 폰 교체 안내입니다. 기존 발신 폰을 유지하려면 변경을 취소하세요.

  2. KEY 인증을 마칩니다.

    정보 화면의 앱 이름을 10번 누릅니다. 표시된 KEY를 위 계산기에 입력하고, 계산된 인증코드를 삼성 인증창에 넣어 개발자 화면으로 진입하세요. 인증 없이 DeveloperActivity만 직접 실행하는 방식은 이 절차를 대신하지 않습니다.

  3. 테스트 사용을 켜고 역할을 선택합니다.

    인증을 마친 개발자 화면에서 테스트 사용 스위치를 ON으로 둡니다. 이미 ON이면 끄지 않고 그대로 둡니다. Device Type에서 수신은 sd, 발신은 pd를 선택하세요.

    이 드롭다운은 개발자 설정의 선택값입니다. 선택 표시가 바뀐 것만으로 실제 CMC 역할이 적용된 것은 아닙니다.

  4. Apply and Reset을 반드시 눌러 적용합니다.

    이 가이드의 개발자 화면 경로에서는 역할을 선택한 뒤 Apply and Reset을 반드시 눌러 적용하세요. CMC 9.1.00.15에서는 이 단계가 실제 역할 변경을 실행하므로 선택 사항이 아닙니다. 버튼 이름이 Apply and Reset APP으로 표시되는 버전도 있습니다. CMC 초기화·재부팅 후에는 CMC 초기 설정과 기기 연결을 다시 진행하세요.

    인증을 마친 동일한 개발자 화면에서 진행하세요. 인증 없이 이 버튼을 누르면 선택한 역할 대신 기기의 기본 역할로 초기화될 수 있습니다. 서버 등 다른 개발자 옵션은 임의로 변경하지 마세요.

  5. 기기 연결 후 전화·문자를 시험합니다.

    삼성 계정 확인, 필요한 QR 연결과 통화·메시지 사용 설정을 진행합니다. 처음 시험할 때는 두 기기를 같은 삼성 계정과 같은 Wi-Fi에 두면 확인하기 쉽습니다. 역할 선택과 실제 연결·수신 성공은 별개이므로 전화와 SMS를 각각 확인하세요. 발신으로 되돌릴 때도 인증된 개발자 화면에서 pd를 선택하고 적용하는 절차를 따릅니다.

이 안내는 CMC 9.1.00.15 기준입니다. 다른 버전에서는 화면과 설정 절차가 다를 수 있습니다.
