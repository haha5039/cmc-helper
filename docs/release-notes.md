# CMC Helper 1.3.1 — 역할 전환 보호 및 연결 안정성 개선

CMC 준비 화면을 실행하기 전에 중단 기록·외부 변경·복원할 수 없는 역할·권한·설치 상태를 검사합니다. 진행할 수 없는 작업이 먼저 CMC 통화·메시지 사용을 끄는 경우를 줄였습니다.

- 준비 중 역할이 바뀌면 기존 확인으로 덮어쓰지 않고 중단.
- Shizuku 엔진에서도 역할 쓰기 직전에 CMC 전체·통화·메시지 꺼짐 재확인.
- 이전 Shizuku 권한 요청의 타임아웃·늦은 응답이 새 요청을 취소하는 문제 수정. 서버 종료 시 승인 대기 해제.
- 계산 결과가 없는 화면에서 불필요한 1초 타이머 제거, 표시 중 초 경계에 맞춰 갱신.
- 추가 권한 없음. 기존 KEY 계산기와 개발자 화면 바로가기 유지.
