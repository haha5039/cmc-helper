# CMC Helper 1.0.0 — 초기 프리릴리스

휴대폰에서 CMC 수신 역할을 지정해도 실제 기기 분류와 다르면 삼성 CMC가 발신 역할로 되돌립니다. 이 버전은 삼성 내부 역할 예외(test_flag)를 루트 호출 없이 설정·해제하고, 역할을 백업·적용·검증·복원합니다.

## 검증 범위와 남은 일

## 설치

APK 설치 후 README의 ADB 준비·역할 적용 절차를 실행하세요. 최소 권한 경로에서는 `tools/device.py`가 역할 변경 때만 권한을 부여하고 다시 회수합니다. 삼성 기본 CMC 화면에서 같은 삼성 계정·발신 휴대폰·QR 연결을 확인해야 합니다.

## 서명

local signing helper·Morphe와 같은 인증서를 사용하고 APK 인증서를 검증했습니다.

```text
SHA-256 fac61745dc0903786fb9ede62a962b399f7348f0bb6f899b8332667591033b9c
```

첨부된 `SHA256SUMS.txt`로 APK와 소스 패키지의 무결성을 확인할 수 있습니다. 비공개 서명 설정·키, 삼성 원본 APK·디컴파일 코드, 계정 정보·전체 기기 로그는 배포 자료에 포함하지 않습니다.
