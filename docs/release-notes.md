# CMC Helper 1.3.0 — 수동 KEY 인증코드 계산기

앱 상단에 KEY를 직접 입력해 CMC 인증코드를 계산·복사하는 화면을 추가했습니다. 이 기능은 Shizuku 연결 없이 기기 안에서 동작하며 CMC 설정을 바꾸지 않습니다.

- 화면의 5자리 KEY 입력, 대문자·앞뒤 공백 정리, 잘못된 입력 안내.
- 기존 CmcOtp 계산식 재사용 및 기준 UTC 분 표시.
- 분이 바뀌면 자동 갱신하고 복사할 때도 최신 코드 계산.
- KEY 변경 시 이전 결과·복사 비활성화.
- 계산 내역을 파일·로그·서버에 저장하지 않음. 회전·화면 복원 시 입력 상태에서 현재 코드를 다시 계산하도록 구현.

계산식은 CMC 9.1.00.15 기준입니다. 기기 시간이 정확해야 하며 실제 삼성 인증창에 표시된 KEY를 사용해야 합니다. 이 버전에서 별도 발신 휴대폰 연결·전화·SMS 수신 시험을 다시 수행하지는 않았습니다.

기존과 같은 공통 인증서로 서명한 업데이트 APK입니다. versionCode 4, com.haha5039.cmc.
