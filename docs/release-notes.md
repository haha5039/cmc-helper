# CMC Helper 1.5.0 — 오프라인 가이드와 가이드 방식 전환

계산기 메뉴에 웹과 같은 발신·수신 수동 설정 가이드를 추가했습니다. 가이드는 앱 안에서 오프라인으로 표시하며 스크립트·파일·네트워크 접근을 사용하지 않습니다.

- 역할 카드의 **가이드 방식 전환 · 초기화/재부팅**에서 별도 확인 후 인증 → Device Type 선택 → Apply and Reset APP을 진행합니다.
- 초기화 요청은 앱 내부에 기록하며, 재부팅 후 앱을 다시 열면 역할 값을 확인합니다. 요청을 자동 재실행하지 않습니다.
- 외부에서 바뀐 역할은 **현재 역할로 기록 기준 맞추기**로 명시적으로 확인할 수 있습니다. 기기 설정과 저장된 원래 역할은 유지합니다.
- 기존의 재부팅 없는 일반 전환과 로컬 KEY 계산기를 유지합니다. 추가 Android 권한은 없습니다.

가이드 방식은 CMC 등록·설정 초기화와 기기 재부팅을 요청하며 기존 발신 폰·연결 기기의 연동에 영향을 줄 수 있습니다. 삼성 CMC 초기 설정과 기기 재등록을 다시 진행할 준비가 있을 때 사용하세요. 원래 역할 복원만으로 등록 초기화를 되돌릴 수는 없습니다.

가이드 방식 자동화는 Android 16 이상 / CMC 9.1.00.15 / Shizuku 승인이 필요합니다. 계산기와 수동 가이드 열기에는 Shizuku가 필요하지 않습니다. 새 자동 초기화 경로의 실제 기기 전체 동작은 별도 확인이 필요합니다.

패키지는 com.haha5039.cmc, versionCode 7입니다. 기존과 같은 필수 인증서로 서명한 업데이트입니다. APK·소스·체크섬만 배포하며 실제 기기 기록·로그·스크린샷·개인 환경 값은 포함하지 않습니다.
