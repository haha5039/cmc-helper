# CMC Helper 1.4.0 — KEY 안내와 화면 복원 개선

계산기에 ‘KEY 확인 방법’을 추가했습니다. 삼성 인증창을 여는 앱 이름 10회 누르기와 초기 설정 조건을 앱 안에서 확인할 수 있습니다.

- 회전 시 홈/계산기 스크롤 위치와 KEY 입력·커서 복원. 코드는 현재 시간으로 다시 계산.
- 버튼·상태의 화면 읽기 정보를 실제 표시 텍스트로 정리하고, 인증코드는 한 자리씩 읽을 수 있는 설명 제공.
- 도움말을 연 채 화면이 재생성될 때 기존 창 정리.
- 삼성 CMC가 없거나 비활성인 기기에서는 역할 버튼에서도 정확한 안내. 계산기는 단독 사용 가능.
- 추가 권한 없음. 기존 역할 전환·개발자 바로가기·로컬 KEY 계산식 유지.
