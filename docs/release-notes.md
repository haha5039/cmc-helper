# CMC Helper 1.2.0 — 전환 수정 및 개발자 바로가기

CMC 사용 중에는 역할 변경이 차단되고, 전환 버튼에서 멀리 떨어진 곳에 오류가 표시되어 동작하지 않는 것처럼 보였습니다. 실행 중인 MainActivity를 재사용하는 자체 계측의 동기 대기도 끝나지 않는 경로가 있었습니다.

- 다른 역할로 바꾸기 전 변경 내용을 확인받고, 삼성 CMC의 실제 통화·메시지 사용 스위치를 끈 뒤 역할을 적용합니다. 전역 활성 값만 위조하지 않습니다.
- 화면 시작은 기존 작업 ID와 제한 시간 안의 비동기 확인을 사용합니다. 앱을 종료하는 계측으로 대체하지 않습니다.
- 필요한 수신 예외는 삼성 초기 설정이 살아 있을 때 먼저 준비합니다. 초기 설정 전이라면 필요한 절차를 바로 안내합니다.
- 역할 적용 후 오래된 CMC 설정 창만 정리해 새 역할 화면으로 다시 열 수 있게 했습니다. CMC 강제 종료·데이터 삭제·재부팅은 하지 않습니다.
- 같은 역할 선택과 취소는 CMC 사용을 끄지 않습니다. 결과를 역할 버튼 옆에도 표시하고 오류 Toast를 추가했습니다.
- 이미 승인된 Shizuku는 엔진만 자동으로 다시 연결하며 설정 작업은 재전송하지 않습니다.
- **삼성 CMC 개발자 화면 열기** 바로가기를 추가했습니다. About 인증을 거쳐 실제 DeveloperActivity를 열어 두며, 앱이 스위치·Reset을 누르지 않습니다. 삼성 화면 자체는 진입 시 기존 개발자 상태를 반영할 수 있습니다.

## 검증

역할 값과 실제 기기 등록은 별개입니다. 전환 후 삼성 CMC 초기 설정·사용 재개·QR 연결이 필요할 수 있으며, 앱은 사용을 자동으로 다시 켜지 않습니다. 실제 전화·SMS 수신과 발신 휴대폰 재연결은 이번 검사 범위에 포함하지 않았습니다.

개발자 화면의 OFF/Apply and Reset은 삼성 CMC 초기화나 재부팅을 요청할 수 있습니다. 바로가기는 그 버튼들을 누르지 않습니다. 개발자 진입·준비는 삼성 CMC의 초기 설정이 완료돼 있어야 합니다.
