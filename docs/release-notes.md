# CMC Helper 1.1.0 — Shizuku 프리릴리스

PC에서 실행하던 ADB 준비·전환 작업을 앱 버튼으로 옮겼습니다. 휴대전화에서 Shizuku를 시작하고 CMC Helper를 승인한 뒤 사용할 수 있도록 구현했습니다.

- Shizuku 승인·연결과 실제 shell/root UID 표시.
- 수신 기능 준비(test_flag ON), 수신/발신 역할 변경, 원래 역할 복원, 조건을 확인한 예외 해제(OFF).
- Shizuku 엔진이 역할을 쓰므로 앱에 WRITE_SECURE_SETTINGS를 자동으로 부여하지 않습니다.
- 기존 쓰기 전 기록·3초 검증·실패 복구·외부 변경 보호 유지.
- 앱을 종료하지 않는 자체 계측, 고정 대상·요청 ID·Helper 작업 확인. 임의 셸 명령이나 Reset으로 대체하지 않습니다.
- 기존 ADB 스크립트는 선택 기능으로 유지.

## 사용 순서

1. 휴대전화에서 Shizuku를 무선 디버깅으로 시작합니다.
2. 앱의 **Shizuku 연결**에서 권한을 허용합니다.
3. 잠금을 해제하고 **수신 기능 준비**를 실행합니다.
4. 삼성 CMC 사용을 끄고 **이 기기를 수신 기기로**를 실행합니다.
5. 삼성 CMC 화면에서 계정·발신 휴대폰·QR 연결을 확인합니다.

무선 디버깅 Shizuku는 재부팅 후 다시 시작해야 합니다. 루트로 시작한 서버는 실제 root UID로 표시합니다. 앱은 `su`를 호출하지 않습니다.
